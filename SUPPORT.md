# Getting help

## Asking for a dataset

Search for it on [publicdata.au](https://publicdata.au/) and vote for it there. The most-voted
requests are built first. A portal page the site cannot find can be sent through the
[National Digital contact page](https://nationaldigital.com.au/contact/).

## A wrong value or a broken file

Open a **Data problem** issue. Say which dataset and version, and link the publisher's own copy
where you can, so the difference can be checked. A value that is wrong at the publisher is the
publisher's to correct; the next version made from their fix will carry it.

## Bugs and feature requests

Open an issue with the bug report or feature request template. Please search existing issues first.

## Security issues

Report them privately as [`SECURITY.md`](SECURITY.md) describes, never in a public issue.

## Anything else

Use the [National Digital contact page](https://nationaldigital.com.au/contact/).
